# CDSS – Evolution 3 (C++ Web Application)

This is a beginner-friendly educational demonstration of a Clinical Decision Support System.
Backend: C++ with Drogon. Database: SQLite. Browser interface: HTML/CSS generated by the C++ server.

## Features
- Home dashboard
- Patient registration
- Patient history
- Health parameter recording
- Simple symptom keyword demonstration

## Important
This is a college demonstration only. It does not diagnose disease, assess emergencies, or recommend treatment.
Do not enter real patient information. Use fictional demo records only.

## Windows setup

Use **Developer PowerShell for Visual Studio 2022** (or a terminal where MSVC `cl.exe` is available).

1. Install Visual Studio Build Tools / Visual Studio with:
   - Desktop development with C++
   - MSVC C++ build tools
   - Windows 10/11 SDK
   - C++ CMake tools
2. Install Git and CMake.
3. Open Developer PowerShell and run:

```powershell
cd C:\
git clone https://github.com/microsoft/vcpkg
cd C:\vcpkg
.\bootstrap-vcpkg.bat
```

4. Go to this project folder (change the path if you extracted it elsewhere):

```powershell
cd C:\path\to\CDSS_Evolution3_CPP
```

5. Install libraries:

```powershell
C:\vcpkg\vcpkg.exe install
```

6. Configure and build:

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=C:\vcpkg\scripts\buildsystems\vcpkg.cmake -DVCPKG_TARGET_TRIPLET=x64-windows
cmake --build build --config Release
```

7. Run the program:

```powershell
.\build\Release\CDSS.exe
```

8. Open this address in your browser:

```text
http://127.0.0.1:8080
```

Keep the terminal running while using the website. Press Ctrl+C in the terminal to stop the server.

## Database
The program creates `cdss.db` automatically in the current working directory. The database is ignored by Git.
