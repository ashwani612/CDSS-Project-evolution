# CDSS Evolution 1 – Basic C++ Prototype

## Overview
A beginner-friendly console prototype written in standard C++.

## Features
- Menu-driven interface
- Patient registration (session only; not saved after exit)
- Basic educational symptom information for fever, cough and headache
- Input validation for menu selection

## Requirements
- C++17 compiler (GCC, MinGW-w64, or MSVC)

## Compile and run (GCC/MinGW)
Open a terminal in this folder:

```bash
g++ -std=c++17 src/main.cpp -o CDSS_Evolution1
./CDSS_Evolution1
```

On Windows PowerShell:
```powershell
g++ -std=c++17 src/main.cpp -o CDSS_Evolution1.exe
.\CDSS_Evolution1.exe
```

## Disclaimer
This is an educational demonstration only. It does not diagnose diseases or provide treatment advice. Use fictional patient data for demonstrations.
